Library

Your library

soroagent files everything you summarize into a searchable personal library. It grows more useful the longer you use it.

Markdown folder (Obsidian, Logseq…) Keep a clean .md file with YAML frontmatter (title, source, tags, dates) for every note in a folder on your computer, such as your Obsidian vault or Logseq pages folder. New and changed notes are written automatically; files you edit there are never overwritten.

Sync across browsers

Keep one library in every browser where soroagent is installed (Chrome, Firefox, Edge, Brave, on any computer). soroagent has no servers, so the shared copy lives in your own Google Drive (in a hidden folder only soroagent can see), encrypted with your passphrase before it leaves this browser. Notes, history, research and preferences sync; each browser keeps its own AI connection and keys; screenshots stay on each device.

Backup & restore

Everything soroagent keeps (snippets, screenshots, summary history and settings) stays on this computer and carries over to every new version automatically. API keys are never included in backups.

Help

Troubleshooting

If the connection test fails:

Ollama isn't running

Open the Ollama app (macOS menu bar / Windows system tray), or run ollama serve. Then download a model, for example ollama pull qwen2.5:7b.

403 Forbidden

soroagent normally handles this. If your setup still rejects the extension, allow extension origins and restart Ollama:

macOS

launchctl setenv OLLAMA_ORIGINS "chrome-extension://*,moz-extension://*"

Windows (PowerShell or Command Prompt)

setx OLLAMA_ORIGINS "chrome-extension://*,moz-extension://*"

Then quit Ollama completely and start it again.

Cloud API errors

Key rejected (401/403): check you copied the whole key and that billing or credits are set up on the provider's site. Rate limited (429): wait a minute, or raise your account's limits. Model not found: pick another model from the list.

LM Studio, llama.cpp, Jan and others

Start the app's local server and use its URL ending in /v1, for example http://127.0.0.1:1234/v1 for LM Studio. In LM Studio, load a chat model and turn on “Enable CORS” if requests fail.

Report a problem

soroagent keeps a short log of its own errors (the last 50) while the browser is open: crashes, site readers that found nothing, replies from the AI it couldn't read, and storage upgrades. Web addresses, page text, emails and keys are removed before anything is logged, and it's never sent anywhere. The button copies a report and opens a new GitHub issue with it filled in, so you can check every line before you submit.

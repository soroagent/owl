# How AI agents use tools
…summary, research and sources…

Chrome, Edge, Brave and Arc write to the folder you pick; Firefox writes to Downloads/soroagent/notes/.

Sync across browsers

Every browser, on any computer, can share one library. The shared copy lives in your own storage and is end-to-end encrypted with your passphrase before it leaves the browser. With Google Drive it sits in a hidden folder only soroagent can see.

Google Drive WebDAV: Nextcloud, ownCloud, Synology, Koofr Private GitHub Gist

Notes merge one by one: newest wins, deletions carry over. Keys and screenshots stay on each device.

Backups and restore

A backup in Downloads/soroagent/ stays up to date automatically. After a reinstall, soroagent finds it and restores everything in one click. Export as Markdown or JSON any time.

Private by design

What you read stays yours.

No soroagent accounts, servers, trackers or analytics. Capture, sync and the Markdown folder are off until you turn them on, and only go where you point them. Read the privacy policy.

  • Your AI
    With a local model, page text never leaves your computer. With a cloud API, it goes only to the provider you chose.
  • API keys
    Encrypted with AES-256-GCM using a key that can't be exported, and sent only to their own provider.
  • Your data
    Library, history and settings live in your browser. Search vectors stay on your device.
  • Google Drive sync
    Asks only for soroagent's own app folder (drive.appdata), never your files.
  • Research
    Reads public web pages only. Addresses on your computer or local network are never fetched.

How it works

Everything runs in your browser.

Web page
The site you're reading
→
Content scripts
Panel in a closed shadow root, page extraction, passive capture
→
Background worker
Makes every model request, so page security policies never block it
→
Your model · Ollama, OpenAI-compatible or Anthropic
Library index · embeddings + BM25
Markdown folder · encrypted sync
Search
Notes are embedded once and stored as 8-bit vectors. Meaning and word rankings are fused with reciprocal rank fusion.
Sync
Gzipped, then AES-GCM encrypted with a key derived from your passphrase (PBKDF2, 250,000 rounds). The passphrase is never stored.
Keys
Only the background worker decrypts them. Settings pages see the last four characters, and first-run entry happens in soroagent's own frame.
